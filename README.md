# 🌞 Google Ads MCP — Connect Claude to Google Ads

> Give Claude direct access to your Google Ads account. Analyze campaigns, optimize bids, add negative keywords and generate reports — all from a chat interface.

Built by [Influenci](https://influenci.com) • Read the [full article](https://influenci.com/blog/connecter-claude-google-ads) (French)

---

## What it does

Once connected, Claude can autonomously:

- 📊 **Analyze** campaign performance, keywords, and search terms
- ⏸ **Pause** underperforming keywords
- 💰 **Update bids** on any keyword
- 🚫 **Add negative keywords** at campaign or account level (shared lists)
- 📈 **Generate reports** (Word, Excel, PDF) with expert recommendations

### Example prompts

```
"Analyze the last 30 days. Which keywords are wasting budget?"
"Pause all keywords with 0 impressions and raise the bid on 'installateur photovoltaïque Corse' to 7€"
"Create a full audit report with recommendations for the next 90 days"
"Add EDF, ANAH, Oreli as negative keywords across all campaigns"
```

---

## Architecture

```
Claude.ai ←→ ngrok (HTTPS tunnel) ←→ MCP Server (local) ←→ Google Ads API
```

The MCP server runs locally on your machine. Your credentials never leave your computer.

---

## Available tools

| Tool | Description |
|------|-------------|
| `get_campaigns` | Campaign performance metrics (N days) |
| `get_keywords` | Keywords with bids and quality scores |
| `get_search_terms` | Real search queries triggering your ads |
| `get_ads` | Active ads and their metrics |
| `get_budget_overview` | Budget and spend by campaign |
| `pause_keyword` | Pause a keyword by ID |
| `update_keyword_bid` | Update max CPC bid |
| `add_negative_keywords_to_campaign` | Add negatives to a specific campaign |
| `add_negative_keywords_to_account` | Create a shared negative list applied to all campaigns |
| `get_negative_keywords` | List existing negative keywords |

## Prerequisites

- Python 3.12+
- A Google Ads **Manager account (MCC)**
- A Google Cloud project with Google Ads API enabled
- A [ngrok](https://ngrok.com) account (free tier works)
- A [Claude.ai](https://claude.ai) account (Pro or Team)

## Installation

### 1. Clone the repo

```bash
git clone https://github.com/ab-solution-dev/google-ads-mcp.git
cd google-ads-mcp
```

### 2. Create virtual environment and install dependencies

```bash
python3.12 -m venv venv
source venv/bin/activate
pip install google-ads google-auth-oauthlib "mcp[cli]" starlette uvicorn
```

### 3. Configure credentials

Copy the template and fill in your credentials:

```bash
cp config.example.json config.json
```

Edit `config.json` with your values (see table below).

**Where to get each value:**

| Field | Where to find it |
|-------|-----------------|
| `developer_token` | Google Ads Manager → Admin → API Center |
| `client_id` / `client_secret` | Google Cloud Console → APIs & Services → Credentials → OAuth 2.0 |
| `refresh_token` | Generated by `setup.py` (step 4) |
| `customer_id` | Your client's Google Ads account ID (no dashes) |
| `login_customer_id` | Your Manager account ID (no dashes) |

### 4. Generate the refresh token (one-time)

```bash
python setup.py
```

A browser window opens → sign in with your Google account → the refresh token is saved automatically in `config.json`.

### 5. Start the MCP server

```bash
source venv/bin/activate
python server.py
```

### 6. Start the HTTPS tunnel (new terminal)

```bash
ngrok http 8080
```

Copy the `https://xxxx.ngrok-free.app` URL.

### 7. Connect to Claude.ai

1. Go to **Claude.ai → Settings → Connectors**
2. Click **"Add custom connector"**
3. Enter: `https://xxxx.ngrok-free.app/sse`
4. Save — connector turns green ✅
